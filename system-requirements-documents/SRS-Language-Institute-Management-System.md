## ۱. مقدمه

### ۱.۱ هدف سند
این سند نیازمندی‌های کارکردی و غیرفункционаی سیستم مدیریت آموزشگاه زبان را به‌صورت استاندارد و قابل‌پیگیری تعریف می‌کند تا مبنای طراحی، پیاده‌سازی، آزمون و پذیرش سیستم باشد.

### ۱.۲ دامنه سیستم
سیستم یک پلتفرم یکپارچه برای مدیریت آموزشگاه زبان است که شامل وب‌سایت عمومی، پنل زبان‌آموز، پنل مدرس و داشبورد مدیریتی می‌شود. سیستم از آموزش حضوری، آنلاین و ترکیبی پشتیبانی می‌کند و فرآیندهایی مانند ثبت‌نام، تعیین سطح، کلاس‌بندی، آزمون، پرداخت، محتوا و گزارش‌گیری را پوشش می‌دهد.

### ۱.۳ ذی‌نفعان

| نقش | توضیح |
|-----|--------|
| مدیر آموزشگاه | مدیریت شعب، کاربران، دوره‌ها، مالی و گزارش‌ها |
| منشی / کارکنان | پشتیبانی ثبت‌نام، پرداخت و ارتباطات |
| مدرس | مدیریت کلاس، حضور و غیاب، نمرات و محتوا |
| زبان‌آموز | ثبت‌نام، یادگیری، آزمون، پرداخت و پیگیری پیشرفت |
| بازدیدکننده عمومی | مشاهده معرفی آموزشگاه، دوره‌ها و درخواست مشاوره |

### ۱.۴ تعاریف و اختصارات

| اصطلاح | تعریف |
|--------|--------|
| SRS | System Requirements Specification |
| SessionType | نوع جلسه کلاس (حضوری، آنلاین، جبرانی و ...) |
| FK | Foreign Key — کلید خارجی پایگاه داده |
| VIP | کلاس ویژه / خصوصی با ظرفیت محدود |
| QR Code | کد دوبعدی قابل‌استعلام روی گواهینامه |

## ۲. توصیف کلی سیستم

### ۲.۱ چشم‌انداز محصول
ایجاد سامانه‌ای یکپارچه برای کاهش خطاهای انسانی، تسریع ثبت‌نام و مدیریت کلاس‌ها، پشتیبانی از آموزش حضوری/آنلاین، پرداخت آنلاین شهریه، صدور کارنامه و گواهینامه، و بهبود تصمیم‌گیری مدیریتی از طریق گزارش‌گیری دقیق.

### ۲.۲ معماری منطقی (سطح بالا)

```
[React + Bootstrap]  ←→  [FastAPI API]  ←→  [SQL Server]
   Frontend UI              Backend/REST         Persistence
```

- **Frontend:** رابط کاربری واکنش‌گرا با React و Bootstrap
- **Backend:** سرویس‌های REST و منطق کسب‌وکار با FastAPI
- **Database:** ذخیره‌سازی ساخت‌یافته در SQL Server با رعایت یکپارچگی ارجاعی (FK)

### ۲.۳ مفروضات و وابستگی‌ها
- کاربران به اینترنت پایدار دسترسی دارند.
- درگاه پرداخت آنلاین در دسترس است.
- سرویس ارسال پیامک و ایمیل پیکربندی می‌شود.
- احراز هویت و کنترل دسترسی مبتنی بر نقش پیاده‌سازی می‌شود.
- استاندارد سطح‌بندی زبان (مانند CEFR یا معادل آموزشی آموزشگاه) تعریف می‌شود.

### ۲.۴ محدودیت‌ها
- پشته فناوری ثابت است: React، Bootstrap، FastAPI، SQL Server.
- رابط کاربری باید فارسی و انگلیسی را پشتیبانی کند.
- سیستم باید روی مرورگرهای رایج (Chrome، Firefox، Edge، Safari) سازگار باشد.
